# Smart Study Planner

A Flask-based academic productivity assistant developed as a college project.

## Features

- Study planning and timetable generation
- Task management
- Progress tracking
- Focus timer
- AI chatbot
- Subject priority management

## Tech Stack

- Python
- Flask
- HTML/CSS
- JavaScript
- SQLite
- Google Gemini API

## Running Locally

1. Clone the repository
2. Install dependencies:
   `pip install -r requirements.txt`
3. Create a `.env` file and add your Gemini API key
4. Run `app.py`

## Note

This project was developed as a college prototype and has known limitations.
